# Nour Academy Teacher Space 🍎

A responsive, lightweight, serverless front-end web application built for Nour Academy teachers to log daily attendance in under 2 minutes, manage student grades, and instantly generate group performance metrics.

---

## ✨ Features

- **⚡ Fast Attendance Tracking:** Log daily student attendance smoothly and efficiently in under two minutes.
- **📊 Grade Management:** Easily record, organize, and update student grades across multiple groups.
- **📈 Group Performance Metrics:** Instantly calculate and visualize overall group progress, averages, and statistics.
- **🔍 Advanced Filtering:** Seamlessly filter students and records by specific groups with dynamic alert reporting.
- **📱 Responsive & Lightweight:** Fully optimized for seamless use across different screen sizes and devices without heavy server dependencies.

---

## 🛠️ Tech Stack

- **Core:** Native JavaScript (ES6+)
- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Tailwind CSS (via Vite configuration)
- **Bundler / Dev Server:** Vite
